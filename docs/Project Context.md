# Project Context

## Vision

Build a modern, scalable, production-ready web application with a clean architecture that remains maintainable as the project grows.

The project prioritizes long-term quality over rapid feature development.

---

## Goals

- Build a solid technical foundation.
- Keep business logic independent from the presentation layer.
- Maximize code reuse.
- Optimize developer experience.
- Create an AI-friendly codebase.
- Reduce technical debt.

---

## Target Users

The exact target audience will be defined as product requirements evolve.

The architecture should remain flexible enough to support future expansion.

---

## Priorities

1. Maintainability
2. Performance
3. Scalability
4. Developer Experience
5. Accessibility
6. Security

---

## Constraints

- TypeScript Strict Mode
- Server Components by default
- Minimal client-side JavaScript
- SEO friendly
- Accessible UI
- Reusable components
- Clean architecture

---

## Non Goals

The project intentionally avoids:

- Over-engineering
- Premature optimization
- Unnecessary dependencies
- Large client bundles
- Duplicate business logic

---

## Success Criteria

The project should remain:

- Easy to extend
- Easy to test
- Easy to document
- Easy for AI tools to understand
- Easy for new developers to contribute

---

## Documentation Rules

Every significant change should update the relevant documentation.

Architecture decisions should be documented before implementation whenever possible.

Documentation should always reflect the current state of the project.
