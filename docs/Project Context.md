# Project Context

## Vision

Modern, scalable, production-ready web application. Clean architecture. Long-term quality over rapid feature development.

## Goals

Solid foundation · business logic independent from UI · maximize reuse · great DX · AI-friendly codebase · low tech debt.

## Priorities

1. Maintainability
2. Performance
3. Scalability
4. Developer Experience
5. Accessibility
6. Security

## Constraints

TypeScript strict · Server Components by default · minimal client JS · SEO-friendly · accessible · reusable components · clean architecture.

## Non-Goals

Over-engineering · premature optimization · unnecessary deps · large client bundles · duplicated business logic.

## Success Criteria

Easy to extend, test, document, AI-understand, and onboard new developers.

## Documentation Rules

Every significant change updates the docs. ADRs before implementation when possible. Docs always reflect current state.
