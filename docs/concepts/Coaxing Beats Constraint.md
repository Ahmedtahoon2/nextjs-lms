# Coaxing Beats Constraint

Why gentle guidance produces better design output than rigid rules.

---

# The Problem

Rigid rules produce rigid output. When you tell an agent "use exactly 16px padding everywhere," you get uniform, lifeless layouts.

---

# The Solution

Coaxing: setting direction and letting the agent fill in the details.

- Set the three dials (direction).
- Define the palette (constraints).
- Let the agent compose within those constraints.
- Review and refine, not dictate.

---

# How It Works

1. Commit to a direction (three dials).
2. Define boundaries (palette, typography, radius).
3. Let the agent build within boundaries.
4. Critique and revise.
5. Never dictate every pixel.

---

# When to Use Coaxing

- New features and components.
- Landing pages and marketing sites.
- Creative layouts and editorial designs.

---

# When to Use Constraint

- Accessibility rules (non-negotiable).
- Security rules (non-negotiable).
- Architecture rules (non-negotiable).
- Anti-slop tells (non-negotiable).

---

# The Balance

- Coax for aesthetics.
- Constrain for quality.
- The three dials are coaxing tools.
- The anti-slop tells are constraint tools.
