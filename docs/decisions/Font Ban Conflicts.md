# Font Ban Conflicts

Resolving conflicts between font-related rules across design skills.

---

# The Conflict

Different skills have different opinions about font usage:

- Taste Skill: Bans Inter for everything without justification.
- Impeccable: Flags Inter as an anti-slop tell.
- Anthropic: Recommends committing to a type direction.
- Vercel: Focuses on typography rules (balance, pretty, line length).

---

# Resolution

- Inter is not banned outright, but using it for everything without justification is flagged.
- Every project should commit to a type direction before building.
- Use the project's chosen font consistently.
- Apply typography rules (balance, pretty, line length) regardless of font choice.

---

# Application

- Choose a font that fits the project's brand and audience.
- Document the choice in `DESIGN.md` or equivalent.
- Apply typography rules from all skills.
- Do not switch fonts mid-project without explicit decision.
