# Quick Reference

## Before Building

- Set three dials.
- Pick palette.
- Define hero thesis.
- Read existing patterns.

## While Building

- Check anti-slop patterns.
- Apply micro-interaction rules.
- Follow typography rules.
- Use design tokens.

## Before Shipping

- Run pre-flight checklist.
- Run audit pipeline.
- Update documentation.
- Verify accessibility.
