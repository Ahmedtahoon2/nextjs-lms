# Tag Taxonomy

Documentation tag system for categorizing and finding documentation.

---

# Priority Tags

- `P1` - Priority 1: Rules and Architecture (highest importance).
- `P2` - Priority 2: Workflows and Quality Audits (very high importance).
- `P3` - Priority 3: Concepts and Micro-details (medium importance).
- `P4` - Priority 4: References and Research (low/reference importance).

---

# Category Tags

- `architecture` - Architecture decisions and patterns.
- `design` - UI/UX design rules and guidelines.
- `quality` - Code quality and testing standards.
- `workflow` - Development workflows and processes.
- `security` - Security rules and practices.
- `performance` - Performance optimization rules.
- `accessibility` - Accessibility standards and guidelines.

---

# Technology Tags

- `nextjs` - Next.js specific rules.
- `react` - React specific rules.
- `typescript` - TypeScript specific rules.
- `tailwind` - Tailwind CSS specific rules.
- `prisma` - Prisma ORM specific rules.
- `shadcn` - shadcn/ui specific rules.
- `zod` - Zod validation specific rules.

---

# Skill Tags

- `taste-skill` - Taste Skill framework rules.
- `impeccable` - Impeccable toolchain rules.
- `mifb` - Make Interfaces Feel Better rules.
- `vercel-guidelines` - Vercel web design guidelines.
- `anthropic` - Anthropic frontend design rules.

---

# Status Tags

- `active` - Currently in use and enforced.
- `draft` - Under development, not yet enforced.
- `deprecated` - No longer recommended.
- `reference` - For reference only, not enforced.
