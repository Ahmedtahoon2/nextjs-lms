# Hero Discipline

Rules for building effective hero sections.

---

# Constraints

- Headline: max 2 lines.
- Subtext: max 20 words.
- CTA visible without scrolling.
- Top padding: max `pt-24`.
- Max 4 text elements in the hero.

---

# Structure

A hero section contains:

1. Headline (thesis of the page).
2. Subtext (supporting the headline).
3. CTA (primary action).
4. Optional: secondary action or supporting visual.

---

# Layout

- Hero must be visible above the fold.
- Never hide the CTA below the fold.
- Use `text-wrap: balance` on the headline.
- Use `text-wrap: pretty` on subtext.
- Body text: `max-w-[65ch]`.

---

# Anti-Patterns

- Hero with more than 4 text elements.
- CTA pushed below the fold by excessive padding.
- Headline that spans more than 2 lines.
- Subtext that exceeds 20 words.
- Hero with no clear visual hierarchy.
- Generic "Welcome to [Framework]" boilerplate.

---

# Design Variance

- Hero should set the tone for the entire page.
- At least one asymmetric element in the hero.
- Break the grid intentionally.
- Use the three dials to calibrate hero intensity.
